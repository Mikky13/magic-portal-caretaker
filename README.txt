# 🔮 Хранитель Порталов — Пульт Управления

Центральный пульт мониторинга и сдерживания межпространственных разломов. Веб-приложение для управления порталами, отслеживания рисков и выполнения действий Хранителя — полностью работает в браузере без сервера.

---

## 📋 Описание

Приложение моделирует систему мониторинга межпространственных порталов. Вам предстоит:

- Отслеживать активные разломы в таблице порталов
- Оценивать риски по формуле: `(Энергия × 1.5) + (100 − Стабильность) + (300 ÷ max(Время до схлопывания, 1))`
- Выполнять действия: стабилизация, закрытие, эвакуация, наблюдатель, пометка «под вопросом»
- Обслуживать порталы: укрепление стабильности, снижение энергии, добавление времени
- Реагировать на автоматически появляющиеся новые разломы
- Вести журнал всех событий и действий

---

## 🚀 Как запустить

### Способ 1: Прямое открытие (самый простой)

1. Скачайте или склонируйте проект.
2. Откройте файл `static/index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Готово — приложение запущено!

> ⚠️ Если при открытии звук не работает — кликните на любую кнопку на странице (браузеры требуют взаимодействия пользователя перед запуском аудио).
